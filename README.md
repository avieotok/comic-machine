# 💥 מכונת הקומיקס

אפליקציית דפדפן שהופכת כל תמונה לדף קומיקס. מצלמים או מעלים תמונה, בוחרים סגנון, כותבים בועות דיבור ומורידים את התוצאה.
הכול רץ בדפדפן: אין שרת, אין התקנה, והתמונות לא נשלחות לשום מקום.

## ✨ מה יש בה

- **צילום ישיר מהמצלמה**, עם החלפה בין מצלמה קדמית לאחורית וטיימר של 3 שניות לסלפי
- **העלאת תמונה** בלחיצה, בגרירה או בהדבקה (Ctrl+V)
- **8 סגנונות קומיקס** עם תצוגה מקדימה על התמונה שלך: קלאסי אמריקאי, פופ־ארט, מנגה, נואר אדום, וינטג' שנות ה־50, אנימה, סקיצה בעיפרון וצבעוני לילדים
- **4 פריסות דף**: תמונה אחת, רצועה, 4 משבצות ופריסת "גיבור"
- **בועות דיבור, מחשבה וצעקה**, אפקט קול וכיתוב, שאפשר לגרור על התמונה
- **הורדה** של התוצאה כקובץ PNG

## 🚀 הפעלה

**במחשב:** מורידים את התיקייה ופותחים את `index.html` בדפדפן.

**באינטרנט עם GitHub Pages (חינם):**
1. מעלים את כל הקבצים לריפוזיטורי חדש ב־GitHub
2. נכנסים ל־**Settings → Pages**
3. ב־**Source** בוחרים `Deploy from a branch`, ואז את הענף `main` ואת התיקייה `/ (root)`, ושומרים
4. אחרי דקה או שתיים האתר זמין בכתובת `https://<שם-המשתמש>.github.io/<שם-הריפוזיטורי>/`

> 📷 **חשוב לגבי המצלמה:** דפדפנים מאפשרים מצלמה חיה רק באתר מאובטח (`https`), ו־GitHub Pages כזה.
> אם המצלמה החיה לא זמינה, בטלפון נפתחת במקומה אפליקציית המצלמה הרגילה.

**בטלפון:** אחרי שהאתר עלה, אפשר לבחור בדפדפן "הוספה למסך הבית" ולהשתמש בו כמו באפליקציה.

## 🗂️ מבנה הקבצים

```
index.html            הדף הראשי
css/style.css         העיצוב
js/app.js             הלוגיקה: מנוע הקומיקס, מצלמה, בועות, הורדה
js/sample.js          תמונת הדוגמה
assets/icon.svg       אייקון
manifest.webmanifest  הגדרות להתקנה במסך הבית
```

## 🧠 איך האפקט עובד

1. **החלקה מצוירת** (מסנן Kuwahara) מאחדת אזורים למשטחי צבע וממשיכה לשמור על קצוות חדים
2. **קווי דיו** מחושבים בשיטת XDoG (הפרש בין שני טשטושים גאוסיאניים)
3. **צביעה לפי סגנון**: הגבלת גוונים, נקודות רסטר, רשתות מנגה, הצללה בעיפרון ועוד
4. **שכבות טקסט** של בועות, אפקט קול וכיתוב מצוירות מעל התמונה
